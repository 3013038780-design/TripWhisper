# TripWhisper

Your AI travel companion, growing with you on every journey. A little whisper, wherever you go.

面向中文欧洲自由行游客的旅行智能体项目，准备参加 EvoTavern 黑客松。

## 当前状态

当前提交包含产品与技术讨论方案 v1.1。实际旅行网页应用尚未开发；本文档中的功能、流程和测试均为规划，不代表已经实现。

## 产品方案

[产品方案与开发路线（HTML）](./产品方案与开发路线.html)

下载 HTML 文件后用浏览器打开即可阅读，无需安装依赖，支持手机布局、目录跳转和打印保存 PDF。

方案包含完整产品蓝图、P0/P1/P2、保留与延后理由、用户工作流程、数据对象、开发推进步骤、验收标准、路演建议和研究来源。

## 开发优先级

- P0：需求采集、行程体检、总行程、每日行动卡、背景手册、固定预订约束下的调整、版本保存、经验复用。
- P1：票券照片触发操作、同行者偏好协调、90分钟空档推荐、经验纠错复核、实际账本、更多识别、导出与小记。
- P2：多城市内容、全面翻译、相册视频、退款跟踪、多设备实时协作、分佣与收费。

EvoMap 接入范围以本场规则和真实接口验证结果为准。

## 团队协作

以 HTML 方案为当前详细范围依据。每次开发先确定输入、处理、输出与验收条件；核心流程通过后再增加增强功能。计划调整必须保留固定预订，并使所有相关交付物来自同一版本。

首个成品目标：手机与电脑都能打开的网页应用。开发使用 Codex 辅助，团队负责产品验收、关键技术审查与实际效果验证。

请勿提交密钥、账户凭证、私人票券或未去标识化的用户旅行资料。
