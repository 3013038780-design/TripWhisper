# TripWhisper · 可交互旅行原型

米兰＋科莫湖 3—5 天的中文旅行工作台。规则驱动原型，未接入真实大模型、实时天气、票务库存、支付或云端存储。

## 已实现

偏好表单、城市概览、按偏好生成安排、每日行动卡、地图与官方入口、模拟预订锁定、雨天/少走路建议及确认、恢复上一版本、预算参考、文字回顾、偏好记忆复用、本机保存、JSON/文字导出、全程打印。

所有金额和交通时长是示范估值。固定预订为模拟约束。实际营业、班次和可用性需用户核实。住宿文本仅用于记录，不表示路线已按酒店地址计算。浏览器存储仅保存当前设备数据，不跨设备同步。

## 开发

Node >=22.13，npm install，npm run dev。npm run build 用于发布构建。npm run lint 和 npx tsc --noEmit 可检查代码。

规则回归：node --experimental-strip-types tests/journey.test.mjs。覆盖预订保留、无原地修改、时间顺序、记忆复用、兴趣分流、预算和非法输入。

WebMCP: 在支持 document.modelContext 的浏览器注册只读 read_trip_summary。当前环境没有可用的 WebMCP 验证上下文，未声称验证其运行。

## 后续接入

接入真实模型时，在服务端保管密钥；模型输出通过结构化校验，并保留 lib/journey.ts 的约束检查。继续补充真实路线/营业信息、票券录入、用户反馈与可靠持久化。不要把演示规则包装成真实模型能力。

# TripWhisper

Your AI travel companion, growing with you on every journey. A little whisper, wherever you go.

面向中文欧洲自由行游客的旅行智能体项目，准备参加 EvoTavern 黑客松。

## 当前状态

当前提交包含产品与技术讨论方案 v1.1。实际旅行网页应用尚未开发；本文档中的功能、流程和测试均为规划，不代表已经实现。

## 产品方案

[产品方案与开发路线（HTML）](./产品方案与开发路线.html)

下载 HTML 文件后用浏览器打开即可阅读，无需安装依赖，支持手机布局、目录跳转和打印保存 PDF。

方案包含完整产品蓝图、P0/P1/P2、保留与延后理由、用户工作流程、数据对象、开发推进步骤、验收标准、路演建议和研究来源。

## 开发优先级

- P0：需求采集、行程体检、总行程、每日行动卡、背景手册、固定预订约束下的调整、版本保存、经验复用。
- P1：票券照片触发操作、同行者偏好协调、90分钟空档推荐、经验纠错复核、实际账本、更多识别、导出与小记。
- P2：多城市内容、全面翻译、相册视频、退款跟踪、多设备实时协作、分佣与收费。

EvoMap 接入范围以本场规则和真实接口验证结果为准。

## 团队协作

以 HTML 方案为当前详细范围依据。每次开发先确定输入、处理、输出与验收条件；核心流程通过后再增加增强功能。计划调整必须保留固定预订，并使所有相关交付物来自同一版本。

首个成品目标：手机与电脑都能打开的网页应用。开发使用 Codex 辅助，团队负责产品验收、关键技术审查与实际效果验证。

请勿提交密钥、账户凭证、私人票券或未去标识化的用户旅行资料。
